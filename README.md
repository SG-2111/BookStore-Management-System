# BookStore-Management-System

A simple Bookstore Management System developed using Python and MySQL.  
This application provides basic functionality to manage book records through a graphical user interface.

Features

- Users are able to use their username and password to login, ensuring safe access
- Add new books to the database  
- Search books by different fields  
- Update existing book details   
- View stored book records in CSV format (Comma Separated Files)


Tech Stack Used:

- Programming Language: Python  
- GUI Library: Tkinter  
- Database: MySQL

Required:

- Python (Version 3.x)
- MySQL Server
- MySQL Connector (To merge MySQL and Python)

To install: (In bash) pip install mysql-connector-python

Steps:
1. Check if MySQL is installed and running. If not, install using https://dev.mysql.com/downloads/installer/
2. Run the program -> python bookstore.py

Note:

Database connection details are defined directly in the Python code.
This project is a part of learning to integrate Python and MySQL and demonstrates basic database operations.
